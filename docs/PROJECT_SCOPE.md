# 项目范围与验收

论文：[Uni-AdaFocus: Spatial-Temporal Dynamic Computation for Video Recognition](https://arxiv.org/abs/2412.11228)。主路线为官方 Uni-AdaFocus-TSM + Jester；参考源码 SHA 为 `8846488310fdd4a18412608006030643e794c36e`。本文件为计划，除已完成的源码固定与静态索引外，以下实验成果均**未验证**。

## 正式目标

官方 Jester 参考配置（目标分支 `README.md:131-145`）：MobileNetV2 Glance + ResNet50/TSM Local，patch size 128，8 帧 Glance、36 帧候选 Focus、最终选 12 帧 Focus。官方权重表 `README.md:152-161` 报告 Top-1 **97.1%**、**18.8 GFLOPs**；这是官方报告，**不是本项目实测结果或验收承诺**。

核心必需成果：双主干、Glance/Local 特征、空间策略与区域裁剪、时间策略与动态选帧、融合分类、训练损失与辅助策略训练的 Jittor 实现；官方 PyTorch 权重基准、Jittor 完整推理、关键算子及梯度对齐、Jittor 训练和同协议准确率比较。用户主导核心算法，Codex 仅按单轮授权辅助工程工作。

独立机制：提前退出脚本生成两阶段 logit 后做阈值评估（见 `docs/TSM_CODE_MAP.md`）；其离线 FLOPs 估计与真实在线提前退出耗时分别报告，不能互代。空间、时间、退出策略消融，以及速度、显存、吞吐量、GFLOPs 分析用于体现完整科研深度。

优秀项目目标：真实可运行代码、真实训练、跨框架公平比较、误差和失败案例分析、可复现仓库。可选增强实验须经用户批准后扩展；不自行替换 Jester、数据划分或论文评价协议。
